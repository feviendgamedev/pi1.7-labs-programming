## Вариант 4 Космический корабль «Аврора»
### Итоговый функционал программы
- Квест на корабле: мостик, кают-компания, реакторный отсек, грузовой трюм, шлюз,
спасательная капсула.
- Цель игрока — восстановить подачу энергии и запустить спасательную капсулу.
- Команды перемещения, осмотра, взятия и применения предметов, инвентаря и подсказки.
- Система состояний: заряд реактора, который уменьшается с каждым ходом.
- Случайные события: утечка кислорода, сработавшая сигнализация, найденный ремонтный
комплект.

**Краткая постановка задачи:** каркас квеста с расходуемым ресурсом.
### Развёрнутое описание
- Приветствие и цель: «Почините реактор и запустите спасательную капсулу».
room, старт — "bridge". 
- Комнаты: bridge, mess, reactor, cargo, airlock, capsule.
- Переменная energy = 100; при каждом переходе уменьшается на 5
- Команды: help, look, go, take, use, exit.
- Флаг reactor_fixed = False; в reactor по use tool → True.
- Победа: в capsule при reactor_fixed == true и energy > 0
- Если energy <= 0 — поражение и break.

### Критерий 100% завершения
- Энергия корректно уменьшается на каждом переходе.
- Реактор можно починить ровно один раз.
- Победа возможна только при починенном реакторе и положительной энергии.
- При обнулении энергии игра корректно завершается поражением.
- В Git есть коммит lab2: каркас «Авроры».
